個資與流量告知

數術知識大挑戰及二十八宿互動圖鑑的網站流量觀測說明

本功能僅供流量分析及異常活動提醒，不會因來源 IP 而封鎖、停權或限制會員、訪客及試玩資格。

一、蒐集內容

當您瀏覽本站首頁或二十八宿互動圖鑑、點擊按鈕或連結時，系統可能由伺服器紀錄來源 IP 位址、事件日期時間、頁面類別、訪問來源類別、事件種類（瀏覽或點擊）及預設控制項代碼（如 button、link）。本流量觀測功能不主動蒐集表單輸入、密碼、電子郵件、題目答案或點擊連結的完整網址。會員等其他既有功能的資料處理不屬於本頁說明範圍。

二、蒐集目的

上述資料用於了解瀏覽及點擊情況，協助排查異常流量。同一 IP 五分鐘內有 80 次活動或 40 次點擊時，管理後台只顯示警示，不會自動或手動封鎖任何 IP。IP 可能由多位使用者共用，不能將 IP 數直接視為獨立人數。

三、資料存取

來源 IP 事件明細由本站既有 Supabase 後端處理，僅供通過管理員身分驗證與權限檢查的人員查看。一般訪客和會員無法直接讀取其他人的 IP 事件明細。本功能不使用廣告追蹤作為資料蒐集目的。

四、保存期間

本功能新增的 IP 事件明細以 30 天為保存目標，透過後續新流量寫入時清理過期紀錄。若沒有新流量，清理可能延後。聚合統計與底層服務日誌可能依各自規則保存，不保證同樣在 30 天內刪除。

五、免註冊暱稱初階挑戰

您可自行輸入暱稱參與初階測驗，答題由伺服器驗證並計入公開前五名排行榜。公開排行榜只顯示暱稱（標示「暱名」）、答題與答對統計，不顯示來源 IP、工作階段憑證或電子郵件。

瀏覽器會儲存一組隨機產生的暱稱工作階段代碼，以便下次在同一瀏覽器繼續累積成績；沒有註冊帳號的暱稱不能證明玩家真實身分。您可由「退出暱稱模式」清除本機代碼，但先前公開排行榜成績不會因此自動刪除。

為觀察同一網路來源的活動，伺服器將暱稱工作階段與來源 IP 事件關聯，僅授權管理員可查看。來源 IP 事件以 30 天為清理目標，暱稱與累積成績則會留存至管理員依法或依規定處理刪除要求。共享 IP 不表示同一個人，也不作為封鎖依據。

六、資料相關問題

如對資料蒐集、查詢、更正或刪除有疑問，可透過 GitHub 專案議題區 請管理者提供私人聯絡方式。該議題區為公開頁面，請勿直接貼出完整 IP、電子郵件、帳號或其他敏感資料。
