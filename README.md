# 二十八宿周天圓盤（GitHub Pages）

本專案為純 `index.html` 的互動式二十八宿圓盤，不使用框架、外部套件或 API。將 `index.html` 上傳至 GitHub 儲存庫根目錄即可供 GitHub Pages 使用。

## 四項修正

1. **北斗星名**：天樞、天璇、天璣、天權（斗魁）→ 玉衡、開陽、瑤光（斗杓）；瑤光亦標示「破軍」。
2. **旋轉軸**：七星圖形以天樞 `(500, 500)` 為中心，角度持續遞減（在 SVG 螢幕座標下，即逆時針），單次旋轉至少 4 圈。星宿外環固定。
3. **星宿圓盤**：28 個等角扇區，4 組各 7 宿；南在上、北在下、東在左、西在右。
4. **精準停止**：抽得星宿索引 `i` 後，計算扇區中心角 `135 + (i + 0.5) * (360/28)`；以瑤光從天樞指向外側的徑向光矢為準，令 `旋轉角 = 扇區中心角 − 瑤光原生方位角`。動畫終點以同一公式計算，不會停在扇區交界。

## 擲爻機制

模擬六次三錢擲爻（每次三枚錢各得 2 或 3，合為 6、7、8、9），共取得 18 個等機率的二元位元，組成介於 0 和 262143 之間的隨機整數；拒絕最末端 8 個值後，對 28 取餘數，以避免餘數抽樣偏差。六爻數值由下往上展示。

**此「擲爻對應二十八宿」為本網站的互動映射設計，不宣稱源於任何古代占法文本。**

## 部署

1. 開啟 GitHub 儲存庫 `nortonGOH/divination-monopoly`。
2. 將本版 `index.html` 取代根目錄同名檔案並 commit。
3. 如尚未啟用 Pages，前往 **Settings → Pages → Deploy from a branch → main / (root)**。
4. 開啟 <https://nortongoh.github.io/divination-monopoly/> 檢查；如剛更新可強制重新整理。
